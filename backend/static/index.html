How it works

Four steps, no setup
STEP 1

Read

Text comes from the PDF's text layer, or OCR for scans. Logos and lines are detected too.

STEP 2

Rebuild

Each value lands in a cell at the same position, size and alignment as on the page.

STEP 3

Edit

Amounts are real numbers. Page Total uses SUM; balances update automatically.

STEP 4

Export

Only changed values are redrawn on the original page. No edits gives back the exact original.
